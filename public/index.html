설정 및 사용 안내

샘플 모드로 사용 중

API 키를 연결하면 실제 시간표를 조회할 수 있어요.

실제 시간표 연결하기

  1. 1

    나이스 교육정보 개방 포털에서 회원가입 후 인증키를 발급받으세요.

  2. 2

    프로젝트의 .env.example을 .env로 복사하고 NEIS_API_KEY에 인증키를 입력하세요.

  3. 3

    터미널에서 npm start로 API 서버를 실행하고 안내된 웹 주소로 접속하세요. 키를 변경하면 서버를 다시 실행하세요.

인증키는 서버에서 사용하며 브라우저로 전달되지 않습니다.

시간표 확인 안내

PC에서는 한 주를 표로, 모바일에서는 선택한 날을 수업 카드로 확인합니다. 수업을 누르면 상세 정보를 볼 수 있어요. 나이스 등록 내용과 학교 현장 일정은 다를 수 있으니 최종 일정은 학교 안내를 확인해 주세요.
